# 🎮 Computer Quiz Game for Kids

A beautiful, interactive, and responsive web-based quiz game designed with a colorful, kid-friendly dark layout inspired by Canva UI. This project tests basic computer knowledge through engaging questions and features a dynamic score tracking system with immediate feedback.

## 🚀 Features
- **Interactive Welcome Screen:** A welcoming portal crafted specifically for younger learners.
- **Dynamic Logic & Layout:** Built using pure JavaScript conditional loops; shows only one question at a time to reduce cognitive pressure on children's eyes.
- **Canva-Inspired UI:** Sleek dark-mode background with soft pink visual elements to minimize glare and screen fatigue.
- **Custom Feedback System:** Provides custom score summaries and encouraging performance-based titles upon completion.
- **Fully Restartable:** Players can instantly reset their scores and play again without reloading the page.

## 🛠️ Built With
- **HTML5:** Semantic architecture using modular block structures (`<div>` and `<span>`).
- **CSS3:** Responsive flexbox layout alignments, custom radial-gradients, and custom shape border radii.
- **JavaScript (ES6):** Dynamic DOM manipulation, array node-list tracking, and click event listeners.

## 🔧 Make It Your Own (Customizable!)
This project is completely modular and developer-friendly. If you want to change the questions or add your own, you can easily open `index.html` and modify the text inside the `.question-block` containers. The JavaScript backend will automatically scale to accommodate your new questions!
